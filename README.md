# Meteor Litematica Printer

Fast printer for Litematica made with Meteor Client

Works best with simple blocks without rotation or other properties like dirt, stone, etc.

## Features
 - placing/breaking blocks based on the currently loaded Litematica schematic
 - filtering via black/white list
 - rendering recently placed/broken blocks
 - switching to blocks from inventory
 - spawning blocks from creative mode

For 1.21+ use the fork of Litematica maintained by [sakura-ryoko](https://github.com/sakura-ryoko)
 - [litematica](https://github.com/sakura-ryoko/litematica)
 - [malilib (needed for litematica to work)](https://github.com/sakura-ryoko/malilib)
